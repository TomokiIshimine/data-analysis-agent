# data-analysis-agent

Claude Code 上で、再現性を重視したデータ分析を一気通貫で行うワークフロー `/data-analysis` を提供するリポジトリです。アプリケーションではなく、Claude Code のワークフロースキル・サブエージェント・How スキルの定義一式（`.claude/` 配下）で構成されています。外部プラグインには依存しません。

## 何ができるか

分析の目的とデータの所在を自然文で渡すと、次の流れを 1 コマンドで進めます。

1. 作業ディレクトリを作る
2. データソースを解決し、ハッシュ付きの台帳とデータプロファイルを作る
3. 分析要件シート（HTML）を起草し、あなたの承認を得る（修正要望は何度でも出せる）
4. プラン立案 → 実行 → 評価の分析ループを回す（既定で最大 5 周）
5. 第三者が同じ手順で同じ結果を出せる再現可能レポート（Markdown）を書く
6. レポートだけを情報源に別のエージェントが追試し、不一致ならレポートへ反映する（既定で最大 3 周）
7. 単一ファイル HTML に清書する

得られる成果物は、データ台帳、データプロファイル、承認済みの要件シート、再現可能な Markdown レポート、再現検証記録、HTML 清書レポート、そして各実行のスクリプト・環境記録・図表を含む実行資産です。実行終了時にそれぞれの絶対パスが提示されます。

## 前提条件

- Claude Code がインストールされていること
- このリポジトリをクローンし、そのディレクトリを作業ディレクトリとして Claude Code を起動すること
- 分析コードを実行できる環境（Python など）。使用する言語・ライブラリは固定されておらず、実行時に環境記録として保存されます
- 追加のプラグインは不要です

## 使い方

Claude Code のセッションで、分析の目的・対象データの所在・知りたいことを自然文で渡します。

```
/data-analysis "sales/2025_orders.csv を使って、四半期ごとの売上の変化と、伸びている商品カテゴリを知りたい"
```

データの所在は、ローカルのファイルパス、ディレクトリ、DB 接続、URL のいずれでも構いません。書かれていない場合は候補が提示され、要件シートの承認時に確定します。

要件シートが起草されると、その HTML ファイルの絶対パスが提示されます。ブラウザで開いて内容を確認し、「承認」または「修正要望」を返してください。承認後は分析ループ・レポート作成・再現検証・清書まで自動で進み、最後に成果物のパス一覧が報告されます。

単発の集計やグラフ 1 枚の作成には向きません。要件定義と再現検証のコストが見合わないためです。

## データの取り扱い

- 元データは既定では複製せず、所在と SHA-256 を台帳に記録し、分析実行の直前に同一性を照合します。
- 非機密かつ小容量のローカルファイルに限り作業ディレクトリへコピーします。機密データは複製せず、レポートにも掲載しません。
- 機密区分は要件シートの必須項目で、承認時にあなたが確定します。
- 作業ディレクトリ `tasks/` は Git 管理外です。

詳細は `.claude/skills/analysis-data-handling/SKILL.md` を参照してください。
